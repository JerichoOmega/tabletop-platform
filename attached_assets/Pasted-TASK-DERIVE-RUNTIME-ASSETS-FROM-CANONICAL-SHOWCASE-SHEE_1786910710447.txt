6. IMAGE PROCESSING RULES
==================================================

Derived assets must be created deterministically from the canonical source.

Do NOT use an AI image generator.

Do NOT use generative fill.

Do NOT hallucinate missing pixels.

Do NOT change the artwork.

Use ordinary image-processing/cropping tools available in the repository environment.

If a crop requires a small amount of transparent-background cleanup, keep it strictly mechanical and non-generative.

If there is ambiguity about where an asset begins/ends, STOP and report the ambiguity instead of guessing.
