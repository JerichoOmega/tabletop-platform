Before considering this complete, fix ONE remaining edge case:

The auto-selection effect is currently:

useEffect(() => {
  if (isPlayerTurn) {
    setSelectedId(currentActorId);
  }
}, [currentActorId, isPlayerTurn]);

This correctly handles normal turn handoffs, but newEncounter() still calls:

setSelectedId(null);

If a new encounter starts with the same current PC and it is still a player turn, currentActorId and isPlayerTurn do not change, so the effect will not fire again. That can leave the newly loaded encounter with no selected PC and therefore no visible action controls.
