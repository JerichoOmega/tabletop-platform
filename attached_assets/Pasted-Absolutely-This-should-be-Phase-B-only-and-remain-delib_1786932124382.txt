The conceptual model is:

interface ViewportState {
  originWx: number;
  originWy: number;
  tileW: number;
  tileH: number;
}

The viewport is presentation state.

It must NOT be placed inside authoritative GameState.

It must never be consumed by:

* rules validation
* action execution
* combat resolution
* movement legality
* ability legality
* RNG
* intent validation

The viewport only determines which portion of the authoritative world is currently presented.
